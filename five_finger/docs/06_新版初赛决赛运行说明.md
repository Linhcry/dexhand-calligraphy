# 2026 初赛 / 决赛程序区分与运行说明

规则来源：`config/competition_20260911.json`，对应官方 2026-09-11 修订版 PDF。

## 一、两个阶段不要混用

| 项目 | 初赛：画龙点睛 | 决赛：古诗书法 |
|---|---|---|
| 入口 | `experiments/run_preliminary_round.py` | `experiments/run_final_round_2026.py` |
| 控制器 | `experiments/preliminary_dragon_eye.py` | `experiments/final_calligraphy_2026.py` |
| 出题/裁判 | `experiments/preliminary_challenge.py` | `experiments/final_challenge_2026.py` |
| 场景配置 | `config/competition_scene_2026_preliminary.json` | `config/competition_scene_2026_final.json` |
| 控制参数 | 控制器内固定安全参数 | `config/profile_final_2026_v1.json` |
| 结果目录 | `outputs/preliminary_2026/` | `outputs/final_2026/` |
| 机会 | 3 次，每次 180 秒 | 1 次，300 秒 |
| 取分 | 3 次中最好一次 | 单次最终得分 |
| 纸面 | 单张龙图（开发用 A3） | 4 张 A3 2×2，总约 594×840 mm |
| 视觉目标 | 识别龙眼并估计圆心/半径 | OCR 识别投影诗题 |
| 过程分 | 触笔 20 + 持笔 3 秒 40 + 蘸墨 80 = 140 | 同左，140 |
| 结果分 | 墨点外缘相对眼半径 r 的区间：≤1.0r=360、≤1.5r=300、≤2.0r=240、≤2.5r=120、>2.5r=0 | 单字 0/1/2，连续 5 字且每字≥1 加 5；质量分归一化到最高 1860 |
| 满分 | 500 | 2000 |

## 二、运行命令

以下命令都在 `five_finger` 目录下执行，建议先设置 UTF-8：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
```

### 初赛开发烟测（只跑 1 次）

```powershell
.\.venv\Scripts\python.exe -m experiments.run_preliminary_round --attempts 1
```

### 初赛正式赛程（3 次取最好）

```powershell
.\.venv\Scripts\python.exe -m experiments.run_preliminary_round --attempts 3
```

### 决赛烟测（已知题目 + 短路径）

```powershell
.\.venv\Scripts\python.exe -m experiments.run_final_round_2026 `
  --development-title 静夜思 `
  --profile config/profile_final_2026_smoke.json
```

### 决赛正式赛程（随机题目 + 4×A3 场景）

```powershell
.\.venv\Scripts\python.exe -m experiments.run_final_round_2026 `
  --profile config/profile_final_2026_v1.json
```

### 实时观看 MuJoCo

默认命令是无头模式（和正式比赛一致，不弹窗口）。调试时加 `--viewer` 即可打开 MuJoCo 实时窗口：

```powershell
# 初赛实时窗口
.\.venv\Scripts\python.exe -m experiments.run_preliminary_round --attempts 1 --viewer

# 决赛实时窗口（smoke 版较短）
.\.venv\Scripts\python.exe -m experiments.run_final_round_2026 `
  --development-title 静夜思 `
  --profile config/profile_final_2026_smoke.json `
  --viewer
```

## 三、关键设计差异

1. **初赛每次都是新场景、新计时、新评分**
   `run_preliminary_round` 每次调用 examiner 重新生成龙图，控制器只能读公开相机图；裁判独立比对私有答案。最后 `best_preliminary_attempt` 取 3 次中最好一次。

2. **决赛只运行一个 300 秒轮次**
   examiner 先投影诗题，控制器 OCR 识别后执行抓笔、蘸墨、四纸连续书写。评分器 `final_scoring_2026.py` 从物理回放给出开发用 0/1/2 代理分，正式成绩仍需现场裁判组。

3. **旧基线没有被覆盖**
   `experiments/blind_competition.py`、`competition_scene.json` 和旧 `run_blind_round.py` 继续保留，用于对照回归。新 2026 程序不修改旧基线的默认结果目录。

4. **规则只存一份**
   所有时间、分值、扣分和纸面约束从 `config/competition_20260911.json` 读取，不要在新实验脚本里再次硬编码 180/300/500/2000。

## 四、官方资料到位后要替换的部分

- 初赛龙图题库与眼睛半径标注
- 决赛诗词题库、投屏格式和标准楷书字帖
- 相机内外参、桌面尺寸和墨池/笔架固定位
- 正式 SDK 的机械臂、灵巧手、CAN FD 和急停接口

在这些发布前，仓库中的初赛龙图和决赛评分均为开发代理，不能当作正式成绩。

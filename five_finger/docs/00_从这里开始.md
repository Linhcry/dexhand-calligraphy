# 从这里开始

这个仓库包含一套可运行的五指灵巧手书写仿真基线，以及为接入比赛真机预留的设备接口。当前已经能做随机题面生成、离线识别、抓笔、保持、蘸墨、书写、录像和结果审计。它仍是仿真验证项目，尚未完成官方 SDK、现场标定和真机低速测试。

## 先完成这五步

1. 在 VS Code 中打开 `five_finger` 文件夹，而不是它的上一级目录。
2. 按照 [VS Code 与仿真操作手册](02_VSCode与仿真操作手册.md) 完成环境检查并打开 MuJoCo。
3. 运行一次固定题目，确认电脑能够完整执行抓笔、蘸墨和书写。
4. 运行一次随机题目，确认控制程序是在生成题面以后才识别文字。
5. 阅读 [训练、调参与验收方法](04_训练调参与验收方法.md)，复制稳定参数文件后再调参。

## 推荐学习顺序

| 阶段 | 先看什么 | 需要达到的结果 |
|---|---|---|
| 1. 会运行 | `README.md`、`lessons/01_minimal.py` | 能打开窗口、暂停和重置 |
| 2. 看懂模型 | `fivefinger/scene.py`、`lessons/02_inspect_model.py` | 能找到机械臂、手、笔、纸和桌面 |
| 3. 看懂控制 | `fivefinger/control.py`、`fivefinger/mujoco_kinematics.py` | 知道目标位姿如何变成关节命令 |
| 4. 看懂自主流程 | `fivefinger/autonomy/supervisor.py` | 能说明识别、抓取、蘸墨、执行和停止条件 |
| 5. 调参 | `config/profile_pinch_reserve_v7.json`、`experiments/train_robustness.py` | 能用多轮随机试验判断参数是否变好 |
| 6. 准备接机 | `fivefinger/autonomy/devices.py`、`config/official_hardware.template.json` | 拿到 SDK 后只替换设备适配层 |

## 当前应使用的基线

- 稳定控制参数：`config/profile_pinch_reserve_v7.json`
- 当前可运行场景：`config/competition_scene.json`
- 2026-09-11 新版规则：`config/competition_20260911.json`
- 完整随机流程：`experiments/run_blind_round.py`
- 多轮鲁棒性试验：`experiments/train_robustness.py`
- 安全和碰撞检查：`fivefinger/robot_surface_monitor.py`、`experiments/contact_force_audit.py`

不要直接覆盖 `profile_pinch_reserve_v7.json`。每次实验先复制为一个新文件，例如 `profile_v7_trial_01.json`，每次只改一组相关参数，并记录随机种子和输出目录。

## 新版规则迁移原则

当前单张 A3 场景是旧基线，用于判断控制器是否退化。新版初赛点睛场景和四张 A3 决赛场景应新增文件实现，验证通过后再切换默认入口。这样可以同时保留：

- 已知可运行的对照场景；
- 初赛点睛任务；
- 决赛四纸书写任务；
- 现场设备适配层。

下一步先实现规则和场景，不急着更换控制算法。只有在相同场景、相同随机种子下，连续多轮结果更好，才保留新的参数或算法。

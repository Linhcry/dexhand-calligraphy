# 训练、调参与验收方法

当前项目的“训练”主要指控制参数搜索、场景随机化和鲁棒性验收。现有程序不是一个已经建立的数据集训练、保存权重、再推理的学习策略。先把可解释的视觉、状态机、运动学和反馈控制做稳定，能更快定位失败原因，也更容易接入尚未公布的正式硬件。

## 训练目标

全自动流程需要同时满足：

1. 识别正确，低置信度时会重新观察；
2. 能接触并稳定夹持毛笔至少 3 秒；
3. 能蘸墨并提起，不掉笔、不大面积洒墨；
4. 笔尖到达正确纸面，接触稳定且不过载；
5. 机械臂、灵巧手和笔都不穿过桌面；
6. 在 180 秒初赛或 300 秒决赛限时内完成；
7. 结束或失败时能安全停止并恢复规定状态。

不能只优化“写出来了”。如果提高字迹接触率的同时造成力峰值、穿模或掉笔，该组参数不合格。

## 参数试验的基本规则

1. 复制当前稳定基线：

```powershell
Copy-Item config\profile_pinch_reserve_v7.json config\profile_trial_01.json
```

2. 一次只修改一组有共同目的的参数，例如只改夹持力或只改笔尖高度。
3. 先用固定题目和固定随机种子复现，再运行随机场景。
4. 每次保留参数文件、种子、代码版本、指标和失败原因。
5. 新参数必须在封存场景上通过，不能只在调参用过的场景上表现好。

## 四阶段课程

### 阶段 1：单技能

分别验证观察、靠近、抓笔、保持、蘸墨、笔尖接触、单笔画和复位。此阶段使用固定物体位置，重点检查坐标、关节方向、限位、力单位和桌面间隙。

### 阶段 2：组合技能

按以下顺序组合：

```text
抓笔 → 保持 3 秒
抓笔 → 蘸墨 → 提起
抓笔 → 蘸墨 → 单笔画
抓笔 → 蘸墨 → 单字
完整题面 → 多字
```

组合失败时退回最后一个通过的阶段，不要同时改视觉、手型和书写轨迹。

### 阶段 3：随机化

逐级加入：

- 笔架平移和旋转；
- 纸面平移、旋转和拼接误差；
- 相机位姿与成像噪声；
- 光照、纹理和深度噪声；
- 墨池液面、笔尖长度和摩擦变化；
- 控制周期抖动与反馈延迟。

每一级先单独测试，再组合随机化。随机范围必须来自规则、官方尺寸或实际标定数据，不能为了让结果好看而缩小到不真实的范围。

### 阶段 4：封存验收

把场景分为三组：

| 集合 | 用途 | 是否允许据此调参 |
|---|---|---|
| 固定开发集 | 快速复现和单步调试 | 允许 |
| 随机训练集 | 搜索参数并统计常见失败 | 允许 |
| 封存验收集 | 模拟未知比赛场景 | 不允许；失败后需建立新版本再整体重测 |

封存集的随机种子由单独文件生成，控制程序运行前不得读取场景真实值。只有独立评分器可以看到真实坐标。

## 参数分组与调整顺序

| 参数组 | 先看什么现象 | 调整方向 |
|---|---|---|
| 视觉置信度 | 误识别、旧帧、目标跳动 | 置信度阈值、重复观测、时序滤波 |
| 预抓取位姿 | 手碰笔架、够不到笔 | 手掌方向、接近距离、抓取轴 |
| 手指闭合 | 掉笔、挤飞、指尖打滑 | 闭合顺序、目标角、速度、力上限 |
| 抬笔与保持 | 提起后漂移或旋转 | 提起速度、夹持余量、反馈增益 |
| 蘸墨 | 未接触、过深、洒墨 | 液面估计、进入深度、停留时间、退出速度 |
| 书写表面 | 离纸、穿纸、力峰值 | 笔尖标定、接触速度、法向控制、滤波 |
| 字形轨迹 | 字太大、越格、笔画拖连 | 缩放、原点、抬落笔高度、速度曲线 |
| 恢复策略 | 失败后继续危险动作 | 超时、重试次数、安全抬升、停止条件 |

增益参数应按“小步调整—固定场景—看日志—随机三轮”的节奏修改。不要把多个版本的有效改动一次合并；先证明每个改动的作用。

## 运行和比较

固定题目：

```powershell
.\.venv-retarget\Scripts\python.exe -m experiments.train_robustness `
  --profile config/profile_trial_01.json `
  --titles 江雪
```

三轮随机题目：

```powershell
.\.venv-retarget\Scripts\python.exe -m experiments.train_robustness `
  --profile config/profile_trial_01.json `
  --rounds 3
```

稳定后再增加轮数。不要并行运行多个物理仿真，它们会争用计算资源并影响计时。

## 每轮必须记录的指标

- OCR 文字、置信度和重试次数；
- 抓笔成功、稳定保持时长、掉笔次数；
- 蘸墨接触和退出是否成功；
- 每个字符的笔尖接触率与越界率；
- 接触力峰值和持续过载时间；
- 机器人与桌面的最小间隙、穿模次数；
- 纸张最大位移；
- 各阶段用时、总用时和停止原因；
- 随机种子、参数文件和运行版本。

当前结果只能称为仿真证据。未接入正式设备前，不能把仿真成功率当作真机成功率。

## 失败诊断顺序

1. **识别错**：先保存原始图像和识别框，检查输入，不先改机械臂。
2. **到达错位**：核对坐标系、单位、相机外参和工具中心点。
3. **抓住后掉笔**：看接触点、笔轴姿态、闭合顺序和夹持反馈。
4. **蘸墨失败**：看笔尖标定、墨面高度和退出轨迹。
5. **离纸或穿纸**：先检查工具长度和纸面标定，再调法向控制。
6. **撞桌或穿模**：立即判失败，检查安全监视器输入和保护距离，不能降低保护门限掩盖问题。
7. **字形不好**：确认物理接触稳定后，再改字形缩放和笔画速度。
8. **超时**：用阶段用时找瓶颈，减少无效等待和路径长度，不跳过安全检查。

## 何时考虑数据驱动策略

只有在取得正式设备接口、稳定采集同步的图像/关节/力数据、建立安全约束和回放验证后，再考虑用示教数据学习抓笔或书写动作。即使加入学习策略，输出仍必须经过关节限位、速度限制、碰撞预测和力限制。比赛主体可以保持规则感知和状态机，只在难以手工描述的局部技能上替换策略。
